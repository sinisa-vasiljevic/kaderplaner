# Kaderplaner Version 74 Offline

## Änderungen in Version 74
- Wasser & Dextro und alle weiteren Dienste besitzen ein einheitliches zweizeiliges Kopf-Layout.
- „Einblenden“ steht bei jedem Dienst in einer eigenen zweiten Zeile.
- Das Warm-Up-Feld ist frei bearbeitbar.
- Die Warm-Up-Angabe wird automatisch im lokalen App-Speicher gesichert.
- Die Warm-Up-Angabe sowie die Spielkleidungsfarben sind Bestandteil des JSON-Exports und werden beim Import wiederhergestellt.
- WhatsApp verwendet weiterhin die gewünschte optische Farbausrichtung.
- Sichtbare Versionsanzeige und Offline-Cache auf Version 74 angehoben.
