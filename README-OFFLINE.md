# Kaderplaner Version 63 Offline

## Änderungen
- Version 63 sichtbar im Kopfbereich.
- Gegner, Datum, Treffpunkt, Anstoß und Adresse haben exakt dieselbe Feldbreite.
- Größere Schrift in den Namensfeldern der Spielerauswahl.

- Gewünschtes KP-Icon für Homescreen und PWA.

## GitHub
Alle Dateien gemeinsam in denselben GitHub-Pages-Ordner hochladen und vorhandene Dateien ersetzen. Danach die App einmal online öffnen, auf Version 63 prüfen, schließen und neu starten.

## Offline-Test
1. App einmal vollständig online öffnen.
2. Zum Home-Bildschirm hinzufügen.
3. Flugmodus einschalten.
4. App vollständig schließen und vom Homescreen neu starten.
5. Oben rechts muss „Offline“ erscheinen.

Die Kaderdaten bleiben wie bisher lokal im Browser gespeichert. Regelmäßig über „Sichern“ exportieren.
